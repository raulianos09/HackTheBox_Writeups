## 📚 Obsidian Vault

**These notes are designed to be viewed in** [**Obsidian**](https://obsidian.md/)**.**

For the best experience, it is highly recommended to:

1. **Duplicate or clone this repository** to your local machine.
    
2. Open Obsidian.
    
3. Select **Open folder as vault**.
    
4. Choose the downloaded repository folder.
    
5. Explore the notes directly inside Obsidian.
    

This allows you to take full advantage of Obsidian's navigation, backlinks, graph view, search, and Markdown rendering.

> 💡 **Recommended:** Use the repository as an Obsidian vault rather than browsing individual Markdown files on GitHub.

## 🧠 Methodology

The writeups generally follow this workflow:

1. **Enumeration** — Port scanning, service discovery, and information gathering.
    
2. **Exploitation** — Identifying and exploiting vulnerabilities to gain initial access.
    
3. **Privilege Escalation** — Moving from an unprivileged user to root.
    
4. **Root** — Obtaining full system access and documenting the attack path.
    

Each machine's notes document the techniques, commands, findings, and lessons learned throughout the process.
